Credentials
TMDB API key
Used to look up movie details and cover art. Get a free key at themoviedb.org/settings/api.
UPCitemdb API key
Used to turn a scanned barcode into a product title. Free tier signup at upcitemdb.com.
GitHub
Used to commit newly scanned movies back to your repo. The token stays only on this device — it's never written into any file that gets committed.
Import collection
Expects columns: Title, Director, Year, Actors, Genre, Medium, IMDbID, NeedsReview. Your existing Title, Director, Year, Actors, and Genre are kept as-is — TMDB is only called to fetch cover art, to fill in any of those fields that were already blank in the CSV, and to look up writing credits (there's no CSV column for those — they always come from TMDB).
Ready.
Backfill writer credits
One-time cleanup for movies you imported before the writer field existed. Scans your current data.json, looks up writing credits on TMDB for anything missing them (up to 4, ranked Screenplay > Writer > Story > Teleplay > Novel), and leaves everything else untouched — cover art, director, cast, all of it stay exactly as they are. Uses the TMDB key above.
Ready.
Add a movie
Scan-to-add isn't wired up yet — it needs the TMDB and UPCitemdb keys above first. Once those are saved, this section will let you scan a barcode and commit the movie straight to your collection.
Debug
Unregisters the app's cached service worker and clears the cache, then reloads so every file — app code and data — is pulled fresh from your GitHub Pages site. Use this if the app looks out of date after a change.
Ready.
