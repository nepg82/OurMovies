Maintenance
Import & export collection
Export
Downloads your whole collection (including anything you've added or edited but not pushed yet) as a CSV in the exact format Import reads, plus a CustomSort column so your series ordering survives. Covers and writing credits aren't stored in the CSV; Import re-fetches them from TMDB.
Import
Import is for starting from scratch. It builds a brand-new data.json and thumbs folder from the CSV and ignores what's already in the app, so committing its result replaces your entire collection. Anything that isn't in the CSV (edits, additions, custom sorts) is lost. If you're unsure, export first.
Expects columns: Title, Director, Year, Actors, Genre, Medium, IMDbID, NeedsReview, and optionally CustomSort. Your existing Title, Director, Year, Actors, and Genre are kept as-is — TMDB is only called to fetch cover art, to fill in any of those fields that were already blank in the CSV, and to look up writing credits (there's no CSV column for those — they always come from TMDB).

Unused cover finder
Looks in the thumbs folder on GitHub for cover files that no record uses. Nothing is deleted until you review the list and confirm; deletion is a single commit, so git history can bring anything back.
Debug
Unregisters the app's cached service worker and clears the cache, then reloads so every file — app code and data — is pulled fresh from your GitHub Pages site. Use this if the app looks out of date after a change.
